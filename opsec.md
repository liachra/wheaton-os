The opsec image is a active delopment image. The intended plan is to
    1. Set default settings for image hardening that a user centric and sensible for the general audience.
    2. Create a user-friendly GUI front end for the SecureBlue provided ujust commands.
    3. (Re)Create custom ujust scripts that fit more inline with wheaton-os goals.
    4. Merge certain Universal Blue suite (Aurora/Bluefin & Bazzite) into the custom SecureBlue image

Once these things are done and functionality proven stable, this image will be merged into the main image(s) becoming the default experience.
